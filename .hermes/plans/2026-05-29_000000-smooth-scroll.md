# Plan: Smooth Scroll Feature

## Goal
Add a "Smooth Scroll" toggle to Nor1c Suite that makes all scrolling (wheel, trackpad, keyboard) silky smooth. Disabled by default. Hardcoded optimal settings — no user-configurable parameters.

## Approach
Two-pronged: CSS `scroll-behavior: smooth` for programmatic scrolls (anchor links, `scrollTo`, etc.) + JS wheel-event interception for mouse/trackpad wheel scrolling (the main source of janky scroll).

### Optimal hardcoded settings (no settings UI)
- Duration: 250ms per scroll step
- Easing: easeOutCubic (`t => 1 - Math.pow(1 - t, 3)`)
- Step distance: proportional to `event.deltaY` (respects fast/slow scrolling)
- Only intercepts vertical wheel events (`deltaY`)
- Skips when modifier keys held (Shift/Ctrl — allows page zoom, horizontal scroll)
- Skips inside `<select>`, `<textarea>`, contentEditable elements
- Skips when target element has its own scroll behavior or is a known scroll container (prevents double-scroll on sites with their own smooth scroll implementations)

## Files to change

### 1. NEW: `src/content/smooth-scroll.js`
Content script. IIFE pattern matching existing scripts (see `gif-blocker.js`).

Structure:
- IIFE wrapping everything
- Inject CSS: `html { scroll-behavior: smooth !important; }` via `<style>` tag
- JS wheel handler:
  - `window.addEventListener('wheel', handler, { passive: false })`
  - `event.preventDefault()` to suppress native scroll
  - `requestAnimationFrame` loop animating `window.scrollBy` with easeOutCubic
  - Cancel ongoing animation on new wheel event (accumulate delta)
- `setActive(val)` toggle: add/remove CSS + attach/detach wheel listener
- `chrome.storage.sync.get(['smoothScroll'])` init (default: `false`)
- `chrome.storage.onChanged` listener for `smoothScroll` key

## Validation
1. Load unpacked extension in Chrome
2. Open popup → "Smooth Scroll" toggle visible, OFF by default
3. Enable toggle → scroll any page with mouse wheel → smooth animation
4. Disable toggle → scroll reverts to native janky behavior
5. Verify anchor links (`#section`) also scroll smoothly when enabled
6. Verify Ctrl+scroll (zoom) still works
7. Verify scroll inside nested scrollable divs works correctly
8. Test on Firefox (same behavior)

## Risks / mitigations
- **Sites with own smooth scroll**: JS handler uses `window.scrollBy` only (not element-level), so page-level wheel is intercepted. Sites that override wheel on specific containers (e.g. Google Maps canvas) may conflict → mitigate by checking if event target is inside a known map/canvas element, but this is edge-case; can revisit if users report issues.
- **Performance**: rAF-based, single animation frame per wheel event, no jank. easeOutCubic is cheap math.
- **Trackpad inertia**: Trackpad fires many rapid wheel events → each cancels previous animation and accumulates delta, producing natural feel. The 250ms duration is per animation, not per event — rapid events chain smoothly.
